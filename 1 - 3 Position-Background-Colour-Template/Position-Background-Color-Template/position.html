CSS Position

This page shows main position values in CSS.

Static

Static is the default. Elements stay in the normal page flow.

Static

Relative

Relative keeps the element in the normal flow, but lets us move it with top, left, bottom and right.

Relative

Absolute

Absolute moves an element relative to it's nearest relative positioned parent.
