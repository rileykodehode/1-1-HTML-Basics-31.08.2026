CSS Measurements

This page shows common CSS Units of measurement. Resize the browser to compare.

Measurements

Pixels (px)

A pixel is an absolute unit. It's size does not depend on the parent element or viewport.

width: 200px

Percent (%)

A percentage is based on the size of the parent element.

width: 50%
width: 50%

em

em is relative to font size. For font-size it is based on the parent's font size. For padding and margin, it is based on the elemen's own font-size.

font-size: 1em

font-size: 2em

rem (root em)

rem is based on the root (html) font size. It is commonly used for consistent font sizes and spacing.

font-size: 3rem

ch (character)

ch is approximately the width of the "0" chracter. It is useful for controlling the readable length of text. Usually 60-70 ch is considered the sweet spot.

vw (viewport width)

vw is based on the browser width. 1vw is 1% of the viewport. Unlike the %, it is not based on the parent. There are plenty of variants of vw and vh, use them as you see fit.

width: 50vw

vh (viewport height)

vh is based on the browser height. 1vh is 1% of the viewport height. We can set the height of a container to 100vh to take up the entire screen, no matter what the size monitor/viewport the user has. Good for hero sections.

height: 30vh

Responsive images

Images can have a fixed size or shrink/grow to fit their container.

fixed image

Responsive image

object-fit

object-fit controls how an image fills it's box.

object-fit:cover

The image covers the entire parent, but depending on the viewport size, we may lose some of our image on the top/bottom or left/right.

object-fit: contain

Contains the image inside the parent, we always see the entire image but this may mean we get whitepsace above/below or left/right.
