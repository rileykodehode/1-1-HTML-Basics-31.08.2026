CSS Variables

CSS variables let us store values and reuse them throughout a stylesheet.

What is a CSS variable?

A CSS variable is a reusable value stored in CSS.

We usually write them inside :root so the whole page can use them.

Example: --main-color: #2563eb;

Using a variable

We use a variable with var().

This uses var(--main-color)

Fallback values

A fallback value is used if the variable does not exist.

This uses var(--missing-color, orange)
