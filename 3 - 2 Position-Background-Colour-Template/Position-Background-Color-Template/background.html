CSS Background Properties

This page shows common background properties in CSS.

background-color

This changes the background color of an element.

background-color-purple

background-image

This adds an image as the background of the element.

background-image

background-repeat

This control whether the background image repeats or not.

background-repeat

background-size

This changes the size and fit of the image.

background-size

background-position

This controls where the image sits.

background-position

background-attachment

Background attachments lets us attach an image to the background image to stay fixed while the page scrolls. (parallax effect)

background-attachment

background-shorthand

A quick way to make backgrounds.

background-shorthand
